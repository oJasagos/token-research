# Token Research

Разборы токенов: рынок, on-chain, фундамент, деривативы, риски и план по позиции — по каждому токену на одной странице.

**→ [ojasagos.github.io/token-research](https://ojasagos.github.io/token-research/)**

Это не инвестиционные рекомендации. Отчёт — снимок на дату сборки; цифры в нём не обновляются задним числом, и это сделано намеренно: видно, что было известно на момент решения.

## Как устроено

Статический сайт без бэкенда. Отчёты лежат в репозитории как JSON, страница рендерит их на клиенте.
Никаких API-ключей, ничего не отваливается при падении внешнего сервиса, старые отчёты остаются
ровно такими, какими были собраны.

```
index.html            список отчётов, поиск, фильтр по сети
report.html?id=<slug> страница отчёта
compare.html          сравнение всех отчётов по ключевым метрикам
assets/css/style.css  вёрстка
assets/js/common.js   форматирование чисел, дат, процентов
assets/js/index.js    главная
assets/js/report.js   рендер отчёта
assets/js/charts.js   графики на SVG
assets/js/anim.js     анимации и прогресс чтения
assets/js/compare.js  таблица сравнения
data/index.json       список отчётов
data/reports/*.json   сами отчёты
data/SCHEMA.md        описание всех полей
```

## Структура отчёта

Вердикт и тезис → рынок (цена, FDV, ликвидность, supply, ATH) → on-chain (холдеры, концентрация,
смарт-мани, потоки с бирж) → фундамент (что за проект, как зарабатывает, TVL, комиссии, аллокации,
разлоки) → деривативы (OI, фандинг, ликвидации) → нарратив → риски по степени → сценарии → план
по позиции.

Секция рисуется только если данные есть. Если по токену не достать холдеров — вкладки не будет,
а не пустая рамка с прочерками. Чего проверить не удалось, то в отчёте названо прямо.

## Локально

Браузер блокирует `fetch` для `file://`, поэтому нужен сервер:

```bash
python3 -m http.server 8000
```

Либо `dist/standalone.html` — весь сайт в одном файле, открывается с диска двойным кликом,
без сервера и без интернета. Пересобирается после изменения отчётов:

```bash
node build-standalone.js
```

## Добавить отчёт

Скопировать `data/reports/_template.json`, заполнить по `data/SCHEMA.md`, добавить запись
в `data/index.json`. Обязательны только `slug` и `symbol`.
