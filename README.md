# Token Research

Личная база разборов токенов. Статический сайт: рынок, on-chain, фундамент, деривативы, риски и план по позиции —
по каждому токену на одной странице.

## Как этим пользоваться

1. Пишешь мне в чат: **«разбери $HYPE»** (или любой тикер / адрес контракта).
2. Я собираю данные из подключённых источников — CoinGecko, DexScreener, DefiLlama, Nansen, Coinglass, Etherscan, Dune, новости.
3. Кладу отчёт в `data/reports/<slug>.json`, добавляю строку в `data/index.json`, пушу.
4. Через минуту отчёт живой на сайте.

Сайт ничего не запрашивает сам — все данные лежат в репозитории. Это значит: ничего не ломается,
ключей никаких не нужно, и старые отчёты остаются такими, какими были на момент сборки.

## Структура

```
index.html            список отчётов + поиск и фильтр по сети
report.html?id=<slug> страница отчёта
compare.html          сравнение всех отчётов по ключевым метрикам
assets/css/style.css  вся вёрстка
assets/js/common.js   форматирование чисел, дат, процентов
assets/js/index.js    главная
assets/js/report.js   рендер отчёта
assets/js/charts.js   графики на SVG
assets/js/anim.js     анимации появления и прогресс чтения
assets/js/compare.js  таблица сравнения
data/index.json       список отчётов для главной
data/reports/*.json   сами отчёты
data/SCHEMA.md        описание всех полей отчёта
data/reports/_template.json  пустой шаблон
```

Файлы `data/reports/_*.json` игнорируются как отчёты — префикс `_` для шаблонов и черновиков.

## Локальный запуск

Браузер блокирует `fetch` для `file://`, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
Через минуту сайт на `https://<username>.github.io/research/`.

Файл `.nojekyll` уже в репозитории — без него GitHub Pages игнорирует папки, начинающиеся с подчёркивания.

Страницы отдают `noindex, nofollow` — в поиск сайт не попадёт. Но URL публичный:
кто знает адрес, тот откроет. Если нужна настоящая приватность — не включай Pages
и открывай локально, либо сделай репозиторий приватным и используй Pages в приватном режиме.

## Добавить отчёт вручную

Скопировать `data/reports/_template.json`, заполнить по `data/SCHEMA.md`, добавить запись в `data/index.json`.
Все поля кроме `slug` и `symbol` опциональны — пустые секции просто не отрисуются.
